# NotebookLM Video Generator

An MCP server that automates generating NotebookLM Video Overviews for coding problems.
Works with any agentic IDE that supports MCP: Claude Code, VS Code Copilot, Cursor, Windsurf, and others.

---

## How It Works

1. You provide a coding problem description.
2. The MCP server generates a structured source document optimized for NotebookLM.
3. Playwright uploads the document to your NotebookLM notebook and triggers Video Overview generation.
4. Generation continues in NotebookLM's cloud. You open the notebook URL to watch or download.

---

## Prerequisites

- Python 3.9 or later
- Google Chrome installed at the default location
- A Google account with access to [NotebookLM](https://notebooklm.google.com)
- A NotebookLM notebook already created (copy its URL from the browser)

---

## Setup (One Time)

### 1. Clone the repository

```bash
git clone <repo-url>
cd <repo-folder>
```

### 2. Run the setup script

```bash
./setup.sh
```

This creates a virtual environment, installs Python dependencies, installs Playwright Chrome,
and generates IDE config files (`.vscode/mcp.json` for VS Code, `CLAUDE.md` for Claude Code).

### 3. Configure your notebook URL

```bash
cp .env.example .env
```

Open `.env` and set:

```
NOTEBOOKLM_URL=https://notebooklm.google.com/notebook/<your-notebook-id>
```

### 4. Log in to Google (one time only)

```bash
./setup_notebooklm.sh
```

This opens a Chrome window. Log in to your Google account, confirm the notebook is open,
then press Enter in the terminal. Your session is saved locally for all future runs.

### 5. Open the folder in your IDE

Open the repo folder in your agentic IDE. The MCP server loads automatically.

- Claude Code uses `.mcp.json`
- VS Code / Cursor / Windsurf use `.vscode/mcp.json`

## Usage

Once setup is complete, use the following tools in order through your IDE's agent chat.

### Step 1 -- Check setup

```
call check_setup
```

Returns `status: ready` if everything is configured. If not, it returns the missing steps.
Always call this first at the start of a session.

### Step 2 -- Generate the source document

```
call prepare_notebooklm_doc with:
  task_markdown: <raw markdown of the coding problem>
  tone: interview | explainer | neutral   (optional, default: neutral)
  target_duration: 1min | 2min | 3min     (optional, default: 2min)
```

The tool returns a `prompt`. Execute that prompt to have the LLM write the source document.

### Step 3 -- Upload and trigger Video Overview

```
call upload_to_notebooklm with:
  document_text: <the document written in Step 2>
  notebooklm_prompt: <the notebooklm_prompt returned in Step 2>
```

Playwright uploads the document to your notebook and types the prompt into the Chat,
which triggers Video Overview generation automatically.

### Step 4 -- Watch or download

Open the notebook URL returned by `upload_to_notebooklm`. Generation runs in NotebookLM's
cloud and takes a few minutes. The video is available to watch and download from the notebook.

## File Reference

| File | Description |
|------|-------------|
| `mcp_server.py` | MCP server with all tools |
| `notebooklm_playwright.py` | Playwright automation script |
| `run_mcp.sh` | MCP server launcher (auto-installs deps on first run) |
| `setup.sh` | One-time setup: venv, deps, IDE config files |
| `setup_notebooklm.sh` | One-time Google login and session save |
| `.env.example` | Template for environment variables |
| `.mcp.json` | Claude Code MCP config |
| `.vscode/mcp.json` | VS Code / Cursor / Windsurf MCP config (generated by setup.sh) |

---

## Tone and Duration Options

| Parameter | Options | Description |
|-----------|---------|-------------|
| `tone` | `interview` | Professional, second-person, reads like a technical interviewer |
| | `explainer` | Warm, first-person plural, podcast-style |
| | `neutral` | Clear and balanced (default) |
| `target_duration` | `1min` | ~250 words, one example only |
| | `2min` | ~500 words, all examples (default) |
| | `3min` | ~750 words, all examples with full constraint walkthrough |

---

## Notes

- The session is stored in `notebooklm_session/` and is gitignored. Each team member runs their own login.
- The notebook URL is stored in `notebooklm_config.json` and is gitignored.
- All sources are added to the same notebook. Clear old sources manually if needed before generating a new video.
- `run_mcp.sh` auto-installs dependencies if `venv/` is missing, so `setup.sh` is optional for IDE users who only need the MCP server.
